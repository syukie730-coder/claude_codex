メッセージカードの送り方

作る → 渡す → 公開する → 届ける

はじめに一度だけ

MacBookのメモに置いておく

メモアプリに「よく使うコマンド」を作って、下の5行を書いておく。以降はそこから ⌘C するだけ。
iPhoneでコピーしてもMacBookには届かないので、コピーは必ずMacBookの中で。

1

📱 スマホでカードを作る

  • 宛名・見出し・一言・本文を入れる
  • ファイル名は英語の小文字と数字で
  • 👀 できあがりを見てみる で確認
📤 MacBookにAirDropで送る
2

💻 MacBookで受け取る

  • 「AirDrop完了」の通知が出たら受信OK
  • 「開く」は押さなくていい

ファイルはDownloadsに入ります

3

📝 メモからコピーする

  • MacBookのメモアプリを開く
  • コマンドの1行を選んで ⌘C

MacBookの中だけのコピペなので必ず貼れます

4

⌨️ ターミナルに貼って進める

一番下が > なら、先に /exit して return

% cd ~/claude_codex
% mv -f ~/Downloads/message.html ~/claude_codex/
% git add .
% git commit -m "message"
% git push

1行ごとに ⌘V → return。5回くり返す

5

✅ 公開できたか確かめる

まずターミナルがこう出ていたら成功
main -> main

そのあと1〜2分待ってから、次の6番へ

6

👀 自分に送って中身を見る

  • スマホのカードアプリに戻る
  • 🔗 公開したURLをLINEで送る をタップ
  • 送る相手に自分を選んで送信
  • 届いたリンクを開いて中身を確認

古い内容が出たら、画面を上から下へ引っぱって更新。それでも古ければもう少し待つ

7

💐 相手に届ける

  • 中身がOKなら、同じボタンをもう一度タップ
  • 今度は渡したい相手を選んで送信

開くのは相手のスマホのブラウザ。アプリを入れてもらう必要はありません

🆘 こんなときは

打っても反応しない
クロちゃんが起動中。/exit と打って return
⌘V しても音が鳴るだけ
iPhoneからコピーしている合図。MacBookのメモから ⌘C し直す
ファイル名が違う
4番の mv の行の message.html を実際の名前に直す
赤い文字が出た
先に進まず、画面をスクショしてクロちゃんに見せる
🍀 あわてず、1行ずつ
